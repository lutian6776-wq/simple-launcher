# 老人桌面 Launcher

一个专为老年人设计的Android桌面启动器应用，界面简洁、按钮大、操作简单。

## 功能特性

### 核心功能
- **一键呼叫**：大按钮设计，快速拨打预设的紧急电话号码
- **快捷应用**：预设常用应用快捷方式（微信、抖音、相机、图库、天气）
- **自定义应用**：可以添加任意已安装的应用到桌面
- **应用配置**：可以为系统应用（相机、图库、天气）选择不同的系统应用替代

### 设计特点
- **大字体**：所有文字都使用较大字号，方便阅读
- **大按钮**：按钮尺寸大，易于点击
- **简洁布局**：3列网格布局，清晰明了
- **高对比度**：使用Material Design 3颜色系统，确保良好的视觉对比

## 技术栈

- **Kotlin**：主要开发语言
- **Jetpack Compose**：现代化UI框架
- **Material Design 3**：UI设计规范
- **DataStore**：数据持久化存储
- **ViewModel**：MVVM架构模式

## 权限说明

应用需要以下权限：
- `CALL_PHONE`：一键呼叫功能
- `CAMERA`：打开相机应用
- `READ_EXTERNAL_STORAGE` / `READ_MEDIA_IMAGES`：访问图库

## 使用说明

### 首次使用
1. 安装应用后，首次打开会请求电话权限
2. 进入设置页面配置紧急电话号码
3. 在设置页面可以配置快捷应用和添加自定义应用

### 配置应用
1. 打开设置页面
2. 在"快捷应用配置"中，点击应用的"选择"按钮可以选择系统应用替代
3. 点击"添加自定义应用"可以添加已安装的应用

### 一键呼叫
1. 在主界面点击红色的大按钮"一键呼叫"
2. 如果已配置电话号码，会直接拨打
3. 如果未配置，会提示前往设置页面配置

## 开发环境要求

- Android Studio Hedgehog | 2023.1.1 或更高版本
- JDK 17
- Android SDK 24 (Android 7.0) 或更高
- Gradle 8.2

## 构建说明

1. 克隆或下载项目
2. 使用Android Studio打开项目
3. 等待Gradle同步完成
4. 连接Android设备或启动模拟器
5. 点击运行按钮构建并安装应用

## 注意事项

- 应用需要设置为默认启动器才能完全替代系统桌面
- 某些功能（如相机、图库）在不同手机厂商的系统上可能需要不同的包名或Intent
- 建议在设置中为系统应用选择对应的系统应用，以确保兼容性
